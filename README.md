🍎 Fruit Image Classification
About the Project

This project is an image classification model created using Google Teachable Machine.

The model is trained to recognize different types of fruits from images.

Fruits Included
Apple
Banana
Orange
Tools Used
Google Teachable Machine
TensorFlow.js
GitHub
How It Works
The user provides an image of a fruit.
The trained model analyzes the image.
The model predicts which fruit is present.
The result is displayed as a fruit name with a confidence score.
