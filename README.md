## 📌 Project Overview

Fruit Image Classification is a deep learning
project that identifies different types of fruits
from images using a CNN model.

The model predicts the fruit category based on
the input image.

## 📂 Categories

1. Apple
2. Bananna
3. Cherry
4. Grapes
5. Strawberry
6. Orange

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Teachable Machine | Programming |
| TensorFlow | Deep Learning |
| Matplotlib | Visualization |
| Kaggle | Image Processing |

## ⚡ How It Works

1. 📸 The user provides an image.
2. 🔍 The AI model analyzes the image.
3. 🤖 The model identifies the object.
4. ✅ It predicts which of the six categories the object belongs to.

## 🎯 Project Objectives

- Classify different fruits.
- Train a CNN model.
- Improve model accuracy.
- Predict fruit images.

## ⚙️ Project Workflow

1. Collect Dataset
2. Preprocess Images
3. Build CNN Model
4. Train Model
5. Evaluate Model
6. Predict Results
